# Event Dictionary

## Primitive Events

### POSE_ACQUIRED

The rider's pose became available.

---

### POSE_LOST

The rider's pose is no longer available.

---

### LEFT_HAND_DETECTED

The left hand became visible.

---

### LEFT_HAND_LOST

The left hand is no longer visible.

---

### RIGHT_HAND_DETECTED

The right hand became visible.

---

### RIGHT_HAND_LOST

The right hand is no longer visible.
